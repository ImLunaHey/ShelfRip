Bundled MKVToolNix (optional)
=============================

Put the portable 64-bit MKVToolNix here so the app can split episodes without a separate install.
The app looks here for mkvmerge.exe, mkvextract.exe and mkvpropedit.exe (after the folder in Settings,
before C:\Program Files\MKVToolNix).

1. Download the portable 64-bit version from https://mkvtoolnix.download/downloads.html#windows
2. Unpack it and copy mkvmerge.exe, mkvextract.exe, mkvpropedit.exe (and the files they ship with) into this folder.
